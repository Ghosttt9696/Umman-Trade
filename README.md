# UMMAN TRADE — сайт компании

Сайт UMMAN TRADE: производство пряжи ALTYN PAMYK, экспорт хлопка, импорт химической продукции, продукты питания и FMCG.
Три языка: **русский**, **английский**, **туркменский**.

## Страницы

| Страница | Файл |
|---|---|
| Главная | `index.html` |
| О компании (с реквизитами) | `about.html` |
| Производство пряжи ALTYN PAMYK | `yarn.html` |
| Экспорт хлопковой продукции | `export.html` |
| Импорт химической продукции | `import.html` |
| Продукты питания и FMCG | `food.html` |
| Контакты и форма заявки | `contacts.html` |

Каждая страница есть в трёх версиях: `docs/ru/…`, `docs/en/…`, `docs/tk/…`.
Корневой `docs/index.html` сам открывает нужный язык (по умолчанию — туркменский; если посетитель уже выбирал язык, откроется его выбор).

## Как устроен проект

```
content/
  site.mjs   ← телефон, e-mail, WhatsApp, адрес сайта — общие для всех языков
  ru.mjs     ← все тексты на русском
  en.mjs     ← все тексты на английском
  tk.mjs     ← все тексты на туркменском
src/
  assets/    ← стили, скрипты, шрифты, картинки
  icons.mjs  ← иконки и иллюстрации продукции
build.mjs    ← сборщик: из текстов и шаблонов делает готовые страницы
docs/        ← ГОТОВЫЙ САЙТ (создаётся автоматически, руками не править)
```

## Как изменить текст или контакты

1. Откройте нужный файл в папке `content/` и поменяйте текст между кавычками.
2. Пересоберите сайт (нужен установленный [Node.js](https://nodejs.org) версии 18 или новее):

   ```bash
   node build.mjs
   ```

3. Готовый сайт появится в папке `docs/`. Открыть его можно прямо в браузере: `docs/ru/index.html`.

Сборщик сам проверяет, что во всех трёх языках одинаковый набор полей. Если вы добавили пункт в русскую версию и забыли про другие языки, он подскажет, чего не хватает.

## Фотографии и видео

Фото лежат в `src/assets/img/`, видео — в `src/assets/video/`. Чтобы заменить или добавить фото,
положите файл с нужным именем (`.jpg`, `.png` или `.webp`) и пересоберите сайт:

| Файл | Где появится |
|---|---|
| `yarn-1.jpg` … `yarn-4.jpg` | «Производство пряжи», галерея «Предприятие» (подписи — в `content/*.mjs` → `yarn.gallery`) |
| `export-1.jpg` … `export-6.jpg` | «Экспорт хлопка», галерея (подписи — `export.gallery`) |
| `yarn-card-white.jpg`, `export-2.jpg`, `import-1.jpg`, `food-1.jpg` | Карточки направлений на главной. Пока нет `import-1` и `food-1`, там показываются иллюстрации |
| `yarn-mill.mp4`, `yarn-cones.mp4`, `cotton-bales.mp4` | Видео на главной и страницах направлений (без звука, по кругу) |

Чтобы добавить больше фото в галерею, добавьте подпись в список `gallery` во всех трёх языках и положите файл со следующим номером.
Фото лучше вертикальные (3:4), около 720×960 px, до 200 КБ.

## Форма заявки

Серверная часть не нужна. Когда клиент нажимает «Отправить заявку», у него открывается почтовая программа с уже заполненным письмом на адрес `email` из `content/site.mjs`. Кнопка «Отправить в WhatsApp» открывает чат с готовым текстом заявки.

## Публикация

Сайт публикуется бесплатно через **GitHub Pages** из папки `docs/` ветки `main`.

### Включить (один раз)
1. GitHub → репозиторий **Umman-Trade** → **Settings** → **Pages**.
2. *Build and deployment* → *Source*: **Deploy from a branch**.
3. *Branch*: **main**, папка: **/docs** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу **https://ghosttt9696.github.io/Umman-Trade/**

### Подключить домен ummantrade.com
1. У регистратора домена (где куплен ummantrade.com) в настройках DNS добавьте записи:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | ghosttt9696.github.io |

   Записи для почты (MX) не трогайте — почта sales@ummantrade.com продолжит работать.
2. GitHub → **Settings → Pages → Custom domain**: впишите `ummantrade.com` → **Save**. Когда проверка пройдёт, включите **Enforce HTTPS**.
3. В `content/site.mjs` поменяйте `baseUrl` на `'https://ummantrade.com'` и пересоберите сайт (`node build.mjs`).

### Другой хостинг
Можно загрузить **содержимое** папки `docs/` в корень сайта на любом хостинге (через FTP или панель управления).
