# Umman Trade — сайт компании

Сайт производителя хлопковой пряжи, хлопкового линта и пуха.
Три языка: **русский**, **английский**, **туркменский**.

## Страницы

| Страница | Файл |
|---|---|
| Главная | `index.html` |
| О компании | `about.html` |
| Продукция (обзор) | `products.html` |
| Хлопковая пряжа | `yarn.html` |
| Хлопковый линт | `lint.html` |
| Хлопковый пух | `fluff.html` |
| Производство | `production.html` |
| Контакты и форма заявки | `contacts.html` |

Каждая страница есть в трёх версиях: `docs/ru/…`, `docs/en/…`, `docs/tk/…`.
Корневой `docs/index.html` сам открывает нужный язык (по последнему выбору посетителя или языку браузера; по умолчанию — русский).

## Как устроен проект

```
content/
  site.mjs   ← телефон, e-mail, WhatsApp, адрес сайта — общие для всех языков
  ru.mjs     ← все тексты на русском
  en.mjs     ← все тексты на английском
  tk.mjs     ← все тексты на туркменском
src/
  assets/    ← стили, скрипты, шрифты, картинки
  icons.mjs  ← иконки и иллюстрации продукции
build.mjs    ← сборщик: из текстов и шаблонов делает готовые страницы
docs/        ← ГОТОВЫЙ САЙТ (создаётся автоматически, руками не править)
```

## Как изменить текст или контакты

1. Откройте нужный файл в папке `content/` и поменяйте текст между кавычками.
2. Пересоберите сайт (нужен установленный [Node.js](https://nodejs.org) версии 18 или новее):

   ```bash
   node build.mjs
   ```

3. Готовый сайт появится в папке `docs/`. Открыть его можно прямо в браузере: `docs/ru/index.html`.

Сборщик сам проверяет, что во всех трёх языках одинаковый набор полей. Если вы добавили пункт в русскую версию и забыли про другие языки, он подскажет, чего не хватает.

## Как добавить фотографии

Положите фото в папку `src/assets/img/` с такими именами (форматы `.jpg`, `.png` или `.webp`) и пересоберите сайт:

| Файл | Где появится |
|---|---|
| `production.jpg` | Главная, блок «Производство полного цикла» |
| `gallery-1.jpg` … `gallery-6.jpg` | Страница «Производство», галерея «Наш цех» |

Пока фото нет, на этих местах показываются аккуратные заглушки.
Рекомендуемый размер — около 1600×1200 px, до 300 КБ на фото.

## Форма заявки

Серверная часть не нужна. Когда клиент нажимает «Отправить заявку», у него открывается почтовая программа с уже заполненным письмом на адрес `email` из `content/site.mjs`. Кнопка «Отправить в WhatsApp» открывает чат с готовым текстом заявки.

## Публикация

### Вариант 1 — GitHub Pages (бесплатно)
1. Влейте изменения в основную ветку (`main`).
2. В репозитории на GitHub: **Settings → Pages → Build and deployment**:
   *Source* — «Deploy from a branch», *Branch* — `main`, папка — `/docs`.
3. Через пару минут сайт будет доступен по адресу вида `https://<имя>.github.io/Umman-Trade/`.
4. Свой домен (например, `umman-trade.com`) подключается там же, в поле *Custom domain*.

### Вариант 2 — любой хостинг
Загрузите **содержимое** папки `docs/` в корень сайта на хостинге (через FTP или панель управления).

После публикации укажите адрес сайта в `content/site.mjs` → `baseUrl` и пересоберите сайт. Так появятся `sitemap.xml` и правильные ссылки для поисковиков (Google, Яндекс).
